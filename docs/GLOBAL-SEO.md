# Worldwide search discoverability — 23 October 2026

The publication is rooted in Africa and welcomes English-reading audiences in every country and territory. Country visibility is measured, not promised. The existing .com domain and canonical public URLs serve the same pages globally. Search engines decide indexing and ranking; government/network restrictions and language preferences can affect access and discovery.

## Implemented

- Removed the short regional list from homepage WebSite structured data. Audience description now refers to worldwide readers; this is descriptive metadata, not a ranking switch.
- Added stable website/person identifiers and consistent WebPage structured data for indexable public English pages. Private, noindex, external and query-token URLs are excluded.
- Broadened editorial SEO drafting guidance from a named-country shortlist to readers in every country and territory. It still forbids geographic keyword stuffing and invented local relevance.
- Country and territory Search Console requests now retain up to 300 returned rows per period, with no regional filter. Other dimensions retain their existing bounds. Saved reports record per-dimension limits so older 100-row snapshots remain accurately labelled.
- Preserved canonical HTTPS URLs, actual English language markup, public sitemaps and RSS, and private-page noindex/no-store boundaries.

## Content and measurement

Publish useful, original articles with clear titles, evidence, descriptive media text and relevant internal links. Explain local abbreviations for readers unfamiliar with the context. Specific countries belong in an article when substantively relevant, not in repeated keyword lists.

The dashboard can show returned search metrics by country once the site's Google Search Console property is connected. Its credentials and authorization remain pending. A missing country row is unavailable, not proof of no readers. Increasing API row capacity does not itself create impressions or rankings.

No duplicate country pages, country redirects, fabricated hreflang lists or unsupported translations were added. Genuine translated editions need reviewed content, unique canonical URLs, visible language switching, reciprocal language annotations and inclusion in sitemaps before publication. English content remains discoverable to English readers worldwide; translated content is a separate editorial programme.
