## APIs and OAuth

The deployed personal-site adapter currently needs:

- Google Search Console API.
- Google Analytics Admin API (property discovery).
- Google Analytics Data API (aggregate reports).
- YouTube Data API v3 (channel discovery/reports; separate optional upload grant).

Configure Google Auth Platform branding and audience using the actual account and domain. Use the verified personal domain, website home, privacy and terms links. Audience/test users must match intended account access; do not choose an organisation-only audience if the owner must connect an account outside that organisation. Confirm Google's current verification and testing requirements in the console.

Create a **Web application** OAuth client named **Waithaka Website Integrations**. This is for the website's existing account connections; it does not add Google sign-in to Writer authentication.

Register these exact redirect URIs, as generated by the deployed application:

```
https://www.waithakandegwa.com/write/connections/callback/google_search_console
https://www.waithakandegwa.com/write/connections/callback/google_analytics
https://www.waithakandegwa.com/write/connections/callback/google_youtube_read
https://www.waithakandegwa.com/write/connections/callback/google_youtube_upload
```

The flow is server-side. Do not add wildcard callbacks or unrelated hosts. If an authorised JavaScript origin is requested, use only `https://www.waithakandegwa.com` for this site; it is not a substitute for the redirect URIs.

The application requests identity (`openid`, `profile`, `email`) plus separate service permissions:

| Connection | Permission |
| --- | --- |
| Search Console | `https://www.googleapis.com/auth/webmasters.readonly` |
| GA4 reporting | `https://www.googleapis.com/auth/analytics.readonly` |
| YouTube read | `https://www.googleapis.com/auth/youtube.readonly` |
| YouTube upload | `https://www.googleapis.com/auth/youtube.readonly` and `https://www.googleapis.com/auth/youtube.upload` |

Keep upload authorisation separate from reporting. Do not request Gmail inbox access for SMTP mail delivery.

## Finish in Writer

Save the OAuth client ID and secret in Writer → Social connections → App settings → Google. Secret fields are encrypted by the application. Do not paste secrets, passwords or verification codes into chat or Git.

Then authorise each reporting connection, select the exact returned Search Console property, GA4 property and personal YouTube channel, and verify one aggregate report. Connecting Google does not create a GA4 property, grant ownership of a Search Console site, confirm a YouTube channel or release an upload automatically.
