# Voice capture and presentation
Owner-only /write/voice records or uploads clips (4 MB maximum, browser recording stops at ten elapsed minutes), with playback, download and explicit private save. Browser permission is requested only on Start. Files use private S3 AES256 or protected local storage; encrypted metadata is scoped to the current user; hashes are verified before playback or AI.
Google Gemini transcription is explicit consent per recording, stateless inline audio, original language, no tools or remote file URL. Failures preserve audio and typed text. It has not yet been proven with a live speech recording. The Responses-only OpenAI key is not expanded to another API.
Editable text can create a private note or unpublished article draft, transactionally and idempotently. Existing editors handle report review, sharing, social variations and publishing approval. No voice action sends mail or publishes.
Notes/reports support a small escaped-text format with bold, italic, headings, lists and quotes; semantic rendering applies to generated reports, emails and captured drafts. Caption tools operate on actual text: bullets, numbering, live preview, copy, optional Unicode emphasis and conversion back to plain letters. Unicode emphasis is labelled as characters, not native formatting; no Markdown/HTML is injected into social captions.
